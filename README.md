# itmo_cv_course

В этой ветке содержится решение 1-ого ДЗ по курсу CV. Данное ДЗ состоит из двух частей - обнаружение "перетекших" изображений из обучающего набора в тестовый, а также группировка всех изображений в кластеры, включающие в себя изначальные и аугментированные версии одного примера.

Все использованные библиотеки указаны в `requirements.txt`

Author: Вязников Павел Андреевич

## Поиск утекших изображений

Файл part1.ipynb содержит исходный код решения этой части ДЗ с комментариями. Для поиска "перетекших" изображений были использованы классические CV алгоритмы для обнаружения особых точек изображения (чем больше совпадений между точками двух изображений, тем вероятнее они похожи) - ORB, AKAZE, SIFT.

Для каждого метода сначала подсчитываются особые точки обучающего и тестового поднабора, затем идет их сравнение друг с другом по порогу. Наилучшим по скорости оказался ORB (~30 сек. на обработку и поиск), а по качеству - AKAZE (F1 = 88%). 

## Кластеризация

Файл part2.ipynb содержит исходный код решения этой части ДЗ с комментариями. Задача заключается в разбиении датасета на кластеры так, чтобы каждый из них содержал только аугментированные варианты одного и того же исходного изображения. Для решения использовались те же подходы, что и для первого задания. 

Для каждого метода сначала подсчитываются особые точки всех изображений, затем идет сравнение каждый-с-каждым, образуя кластеры (по порогу). По визуальному сравнению лучше всех оказывается AKAZE, метрики же получаются крайне низкие (доля правильно восстановленных групп), т.к. все подходы не могут идеально повторить ground-truth кластеры (у AKAZE наивысший accuracy = 6%).

## Выводы

В данной работе были решены две задачи по сравнению изображений с использованием алгоритмов ORB, AKAZE и SIFT:

1) В первой задаче для нахождения утекших изображений наилучшим образом показал себя AKAZE, получив наилушие метрики (F1 = 88%);
2) Во второй задаче были применены те же методы, и снова лучше себя показал AKAZE (в визуальном сравнении, метрики везде крайне низкие)
